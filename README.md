# 動画開発標準Assy

Microsoft 365 Copilot Chat(ベーシック。Microsoft 365 のライセンスに含まれ、追加のライセンスが要らないもの。2026年11月7日時点)では、MP4 は、入力の対象になっていません。
この標準は、コードインタープリターを使って、**MP4 の説明動画を書き出させる方法**を、3 つのファイルにまとめたものです。
「標準」としているのは、組織の中で、誰が使っても、一定の安定した出力が得られるようにするためです。

## 使い方

1. Releases から `video-dev-standard-assy.zip` をダウンロードして、展開する
2. Copilot Chat のモードを、メニューの **GPT の Think Deeper** にする(選ぶと、左上の表示は「GPT-5.6 Sol 考える」になります。モデルの名前や表示は最近変わったため、環境によっては違うことがあります。2026年11月7日時点)
3. `01_procedure.md` `02_reference.md` `03_plan_and_progress.md` を、1 回のメッセージに添付して、「この資料に従って、始めてください」と送る
4. 質問に答えて、構成案に OK を出すと、動画ができる
5. 作れなかったときは、次のメッセージに `00_make_video.py` を添付して、「続けてください」と送る

## なぜ 3 つのファイルと、Python のファイルなのか

- 入力は、一度に 3 つのファイルまでしかできません。そこで、手順書を 3 つのファイルにまとめ、動画を作るコードも、その中に全文を入れました
- Copilot は、長いファイルの文脈を畳んで(途中を省いて)読むことがあります。そこで、コードはチャットで読み取らせず、ファイルから取り出し、行数と sha256 で全文がそろっているかを確かめてから実行します
- 確かめられなかった場合に備えて、Python のファイル(`00_make_video.py`)を、次の入力で入れられるようにしています

## 注意

- 「自動」「クイック応答」など、GPT の Think Deeper 以外では、動画を作る前に止まります
- お使いの環境で同じように動くとは限りません。手順書の環境確認が、開発環境との差分を表示します
- うまくいかなかったときは、Issue で教えてください(機密情報や個人情報は、書かないでください)
